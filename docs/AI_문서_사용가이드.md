# AI 에이전트용 문서 사용 가이드

> **대상**: UI 디자인 생성·서비스 재구현·사업계획서 작성 등을 위해 본 프로젝트 문서를 AI 에이전트에 넣는 경우.  
> **목적**: 어떤 문서를 어떤 순서로 참조하면, **문서만으로 최초부터 서비스를 스스로 제작할 수 있을 정도**로 구체적인 스펙을 전달할 수 있는지 안내.

---

| 문서 | 용도 | 핵심 내용 |
|------|------|-----------|
| **[화면정의서.md](./화면정의서.md)** | UI/와이어프레임·화면 설계 | 전체 화면 목록(랜딩·모의고사 목록·퀴즈·결과·대시보드·관리자 등). 각 화면의 **정의·목적·필수 기능·주요 UI 요소·이동 경로**. |

- **UI 디자인을 뽑을 때**: 화면정의서를 먼저 주고, 필요 시 기능정의서·회원정책으로 화면 간 이동·권한·플로우를 보강하면 됩니다.

## 2. 실서버 vs 베타(추후 구현 예정)

- **실서버(프로덕션)**: 현재 정식 서비스. 랜딩·회차 목록·퀴즈·결과·대시보드·결제·관리자 등이 문서에 반영되어 있습니다.
- **베타 전용 기능**(강제 로그인·오리엔테이션(OT)·쿠폰 입력·난이도 선택·온보딩 상태 등)은 **실서버에 추후 구현 예정**으로, 문서 내에 "(실서버 추후 구현 예정)"으로 표기되어 있습니다. 베타 플로우를 실서버 스펙에 포함하려면 해당 문단을 "추후 구현"이 아닌 "필수 기능"으로 해석하면 됩니다.

## 4. AI에 넣을 때 추천 순서

1. **화면/UI 목적**: 화면정의서 → 회원정책(접근·등급).
2. **플로우/로직 재구현**: 기능정의서 → 화면정의서(이동 경로) → 회원정책.
3. **사업계획서·설명 자료**: 화면정의서(목적·기능) + 회원정책(등급·정책) + 기능정의서(합격률·Elo·맞춤형 요약).
