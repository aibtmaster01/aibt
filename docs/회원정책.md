# 회원정책 (Membership & Access Policy)

> **목적**: 회원 등급·접근 제어·쿠폰·탈퇴 등 회원 관련 정책을 한 문서에 정리. AI 에이전트·운영·사업계획서 작성 시 참조.  
> **범위**: 실서버 기준. 베타 전용(온보딩 상태·쿠폰 강제 등)은 "(실서버 추후 구현 예정)" 표기.

---

## 1. 회원 등급 정의

| 등급 | 조건 | 비고 |
|------|------|------|
| **Guest** | 비로그인(`user === null`) 또는 해당 자격증이 `subscriptions`에 없음 | 1회차만 제한된 문항(예: 20문항) 체험 가능 |
| **Free** | 로그인 + 해당 자격증 구독 있음 + `paidCertIds`에 해당 certId 없음 | 1·2회차만 풀이 가능. 3회차 시도 시 결제 유도 |
| **Premium** | `paidCertIds`에 해당 certId 포함 + `expiredCertIds`에 없음 | 전 회차(고정·맞춤형·집중학습) 이용 가능 |
| **Expired** | `paidCertIds`에 있으나 `expiredCertIds`에 포함 | 유료 회차 잠금. 오답노트 등 일부만 안내 가능 |
| **Admin** | Firestore `users/{uid}.isAdmin === true` | 해당 자격증 문항이 있으면 전 회차 접근. 관리자 메뉴·라우트 노출 |

- **구현 위치**: `examService.getUserGradeForCert`, `examService.checkExamAccess`. 등급 판단은 `users/{uid}` 문서의 `memberships`, `paidCertIds`, `expiredCertIds`, `isAdmin` 기준.

---

## 2. 접근 제어(회차별)

| 등급 | 1회차 | 2회차 | 3회차 | 4회차~(맞춤형·약점 공략) |
|------|--------|--------|--------|----------------------------|
| Guest | ○ (20문항 제한) | × | × | × |
| Free | ○ | ○ | × (결제 유도) | × |
| Premium | ○ | ○ | ○ | ○ |
| Expired | × | × | × | × |
| Admin | ○ | ○ | ○ | ○ |

- **3회차 시도 시 Free**: `checkExamAccess` 반환 `{ allowed: false, reason: '열공모드로 합격권에 진입하세요.' }` → 결제 유도 모달 노출.
- **UI**: 잠금 회차는 카드에 잠금 아이콘·배지. 클릭 시 결제 유도 또는 "이용권을 구매해 주세요" 안내.

---

## 3. 가입·인증

- **가입 방법**: 이메일+비밀번호, 구글 OAuth. (베타: 구글만 노출 가능. 실서버 추후 동일 옵션 구현 예정.)
- **이메일 인증**: 정책에 따라 "미인증 시 로그인 제한" 또는 "미인증도 로그인 허용(앱 내 재발송 안내)". 현재는 미인증 허용 가능.
- **Firestore 사용자 문서**: `users/{uid}`. 생성 시점: 최초 로그인(이메일/구글) 시. 필드: email, name(familyName, givenName), created_at, isAdmin(false), memberships, subscriptionIds, paidCertIds, expiredCertIds, is_verified 등. (베타: onboarding_status 0|1|2. 실서버 추후 구현 예정.)

---

## 4. 멤버십·이용권

- **저장 위치**: Firestore `users/{uid}.memberships`. 구조: `{ [certCode]: { tier: 'PREMIUM'|'FREE', start_date, expiry_date, target_schedule_id } }`.
- **paidCertIds / expiredCertIds**: memberships에서 파생. tier가 PREMIUM이고 expiry_date가 오늘 이상이면 paidCertIds, 미만이면 expiredCertIds에 certId 포함. 클라이언트는 이 배열로 등급·접근 제어.
- **수기 부여(관리자)**: 관리자 회원관리에서 "수기 결제/권한 수정" → memberships 해당 자격증 tier·expiry_date 수정 → 저장 시 즉시 반영.

---

## 5. 쿠폰 (실서버 추후 구현 예정)

- **컬렉션**: Firestore `coupons/{code}`. 필드: 자격증·유효기간·사용 횟수 제한·할인 또는 무료 기간 등.
- **사용( redeem )**: 로그인 사용자가 코드 입력 → 유효성 검사 → `users/{uid}.memberships`에 해당 자격증 PREMIUM·expiry_date 반영. 사용 이력 기록(중복 사용 방지).
- **관리자**: 쿠폰 코드 생성·목록·폐기. AdminBilling 또는 전용 화면.

---

## 6. 관리자 권한

- **부여**: Firestore `users/{uid}.isAdmin = true` 수동 설정(콘솔 또는 백엔드 스크립트). 복구 절차는 `ADMIN_ACCOUNT_RESTORE.md` 참고.
- **권한 범위**: 회원 목록·학습현황·수기 결제/메모/정지/기기 초기화, 문제 관리(문항 수정), 자격증 설정, 쿠폰 등록/폐기, 오류 로그 조회 등. Firestore 규칙에서 `get(/databases/$(database)/documents/users/$(request.auth.uid)).data.get('isAdmin', false) == true` 일 때만 users·exam_results·stats·daily_visits·error_logs 등 읽기 허용.

---

## 7. 기기 초기화

- **의미**: 해당 사용자의 `users/{uid}.registered_devices` 배열을 비움. 이후 새 기기에서 로그인 시 다시 등록.
- **실행**: 관리자 회원관리에서 "기기 초기화" → 확인 모달 → clearUserDevices(uid).

---

## 8. 이용 정지

- **필드**: `users/{uid}.isBanned` (boolean). true 시 앱에서 로그인 차단 또는 제한 화면 노출(구현 정책에 따름).
- **실행**: 관리자 회원관리에서 "이용 정지" / "정지 해제" → updateUserBanned(uid, true|false).

---

## 9. 탈퇴

- **현재**: 탈퇴 플로우 미구현. 향후 데이터 보관/삭제 정책 결정 후 구현 예정.
- **고려 사항**: Auth 계정 삭제, Firestore users·exam_results·stats 등 개인 데이터 삭제 또는 익명화, 법정 보존 기간.

---

## 10. 개인정보·데이터 저장

- **수집 데이터**: 이메일, 이름, 로그인 제공자(이메일/구글), 응시 이력(exam_results), 학습 통계(stats), 방문 기록(daily_visits) 등. (개인정보처리방침은 별도 문서.)
- **저장 위치**: Firebase Auth(uid·이메일), Firestore users·users/{uid}/exam_results·users/{uid}/stats·users/{uid}/user_rounds 등. 관리자 전용: error_logs, coupon_redemptions, problem_reports 등.

---

*회원정책은 등급·접근·쿠폰·관리자·탈퇴를 정의. 화면별 노출은 화면정의서, 기능별 로직은 기능정의서 참고.*
