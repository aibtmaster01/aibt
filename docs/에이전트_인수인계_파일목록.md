# 다른 에이전트 인수인계 시 보여줄 파일 목록 (.tsx 제외)

> 상대 에이전트가 **.tsx를 받지 않을 때**, 베타·모의고사 제공 로직(문제 수 변경)·가입 플로우를 다루려면 **아래 파일만** 보여주면 됩니다.  
> .tsx(UI·라우팅)는 제외하고, **설정·서비스 로직·타입·문서**만 넘기면 됩니다.

## 3. 모의고사 제공 로직 (문제 수 변경 시)

| 경로 | 설명 |
|------|------|
| **src/constants.ts** | **회차별 문항 수(UI·라벨용)**: `EXAM_ROUNDS[].questionCount` (빅데이터 80/80/80, SQLD 5/20/20 등). 문제 수를 “표시/정책” 수준에서 바꾸려면 여기. |
| **src/services/examService.ts** | **실제 선정 개수**: `STATIC_QUESTIONS_PER_ROUND`(1~3회차 80), `TOTAL_QUESTIONS = 80`, 집중학습용 `SUBJECT_STRENGTH_50_TARGET`(50), `WEAK_FOCUS_50_TARGET`(50) 등. **모의고사 80문항·집중학습 50문항** 변경 시 수정 대상. |

## 5. 넘기지 않아도 되는 것 (.tsx)

- **App.tsx**, **LoginModal.tsx**, **OrientationPopup.tsx**, **ExamList.tsx**, **Quiz.tsx**, **MyPage.tsx** 등은 **모두 .tsx**이므로 상대가 받지 않는다면 **넘기지 않음**.
- 위 **docs**와 **.ts 파일**만으로도 “베타 여부”, “모의고사 80/50 문항이 어디서 정해지는지”, “가입·쿠폰 시 어떤 서비스를 쓰는지”는 전부 파악 가능합니다.  
- 플로우(어떤 순서로 모달이 뜨고, 어디서 서비스를 호출하는지)는 **docs/BETA_유저플로우.md**의 표와 “관련 파일 요약”으로 전달하면 됩니다.

- **모의고사 문제 수 변경**: `docs/05_로직_모의고사큐레이션.md` + `src/constants.ts`(EXAM_ROUNDS.questionCount) + `src/services/examService.ts`(STATIC_QUESTIONS_PER_ROUND, 50/80 상수) + `src/services/aiRoundCurationService.ts`(ROUND5_TOTAL, QUESTIONS_PER_SUBJECT)

이 목록만 전달하면, .tsx 없이도 다른 에이전트가 베타·모의고사 문항 수·가입 플로우를 수정할 수 있습니다.
