# 예측 합격률·과목별 안전도 (계산식·유저플로우·규칙)

> 베타(AiBT) 포함, 합격률 계산(시그모이드)·과목별 안전도 분석의 **계산식·데이터 소스·화면 규칙**을 한곳에 정리.  
> 코드: `gradingService.ts`(채점·합격률), `statsService.ts`(대시보드·안전도).

---

## 1. 용어 정리 (사업/기획 공용)

| 용어 | 의미 |
|------|------|
| **예측 합격률** | “이 실력이면 실제 시험에서 합격할 확률이 얼마나 될지”를 0~99%로 나타낸 지표. 시그모이드 변환으로 합격선(60점) 근처에서 민감하게 반응. |
| **과목별 안전도** | 각 과목의 정답률(0~99%). “과락선(40점)을 얼마나 넘었는지”가 곧 안전 마진. |
| **과락선** | 한 과목이라도 이 점수 미만이면 불합격이 되는 최소 점수(예: 40점). 자격증별로 설정. |
| **안전 마진** | (과목 점수 − 과락선). 양수면 과락 위험 없음, 음수면 과락 위험. |

---

## 2. 예측 합격률 계산 (시그모이드 포함)

### 2.1 처리 위치·시점

- **계산**: `gradingService.computePredictedPassRate()` → 퀴즈 제출 시 1회만 호출.
- **저장**: `users/{uid}/exam_results/{examId}.predicted_pass_rate` (0~99 정수).
- **표시**: 마이페이지·시험 목록 등에서 “최근 시험의 예측 합격률” 또는 “최근 3회 가중 평균”으로 사용.

### 2.2 계산 단계 (기능 유지, 공식만 정리)

1. **과목별 점수 (이미 채점에서 산출)**  
   - `subject_scores`: 과목 번호 → 0~99 점수(%).  
   - 난이도 가중: 문항별 `w_i = 1 + β×(d_i − 0.6)`, 정답 시 가중치만큼 누적 후 과목별 비율로 100점 만점 환산.

2. **원점수 합격률 (0~100)**  
   - `평균점수 = 과목별 점수의 평균`  
   - **과락 패널티**: 과목별 최저점이 과락선(기본 40점) 미만이면  
     `패널티 = (과락선 − 최저점) / 과락선 × 20`  
   - `원점수합격률 = max(0, min(100, 평균점수 − 패널티))`

3. **시그모이드 변환**  
   - 합격선 60점을 중심(변곡점)으로 S자 곡선 적용.  
   - `sigmoid(x) = 1 / (1 + exp(−0.08 × (x − 60)))`  
   - `시그모이드합격률 = round(sigmoid(원점수합격률) × 100)`  
   - 60점 근처에서 작은 점수 차이도 %로 크게 반영되도록 설계.

4. **난이도 보정 (α)**  
   - 해당 회차 문항 평균 난이도 `avgDifficulty` (0~1, 기준 0.6).  
   - `α`: 난이도가 기준보다 쉬우면 0.5~1.0, 어렵으면 최대 1.2까지 상향.  
   - `최종 예측 합격률 = round(α × 시그모이드합격률)`, 0~99 클램프 후 **96% 상한** 적용.

### 2.3 상수 (gradingService.ts)

| 상수 | 값 | 설명 |
|------|-----|------|
| 과락선 기본값 | 40 | 자격증 설정 없을 때 사용 (min_subject_score) |
| 시그모이드 중심 | 60 | 합격선(변곡점) |
| 시그모이드 기울기 | 0.08 | S자 완만도 |
| 과락 패널티 계수 | 20 | 과락선 미만 시 최대 20점 감점 |
| 예측 합격률 상한 | 96 | % 표시 상한 |

## 3. 과목별 안전도 분석 (대시보드)

### 3.1 데이터 소스 우선순위

1. **최근 1회 시험의 과목별 점수** (`exam_results` 최신 문서의 `subject_scores`)  
   - 예측 합격률과 동일한 스케일(0~99%)이라 “안전도”와 “합격률”을 같이 해석하기 좋음.
2. 없으면 **최근 시험들 해당 과목 점수 평균**.
3. 그마저 없으면 **누적 통계** `users/{uid}/stats/{certCode}.subject_stats`의 Elo 기반 이해도(%).

### 3.2 과목별 점수·안전 마진

- **과목 점수**  
  - 최근 2회 이상 있으면 **max(최신 회차 점수, 최근 회차 평균)** 사용 → 한 회차 0점만으로 0%가 되지 않도록 함.  
  - 그 외는 최신 회차 점수 → 최근 평균 → `subject_stats` Elo% 순.  
  - **하한 15%** 적용(예측 합격률과 동일): 표시값 = `max(15, min(99, rawScore))`.
- **과락 기준점 (PASS_LINE)**: 대시보드 표시용 고정값 **40점** (실제 합격 판정은 자격증별 `min_subject_score` 사용).
- **안전 마진**: `안전 마진 = 과목 점수 − 40`  
  - 양수: 과락선 위(안전), 음수: 과락 위험.

### 3.3 트렌드 (상승/하락/유지)

- 최근 시험들에서 해당 과목 점수만 시간순으로 모아, “직전 대비 이번 점수 차이”로 3점 이상이면 상승, −3점 이하면 하락, 그 사이면 유지.

## 4. 유저 플로우 (저장 → 표시)

1. **모의고사 풀기** → 제출 시 `submitQuizResult()` 호출.
2. **채점**  
   - 과목별 점수(난이도 가중) → `subject_scores`  
   - 합격 여부(`is_passed`), **예측 합격률** `computePredictedPassRate()` → `predicted_pass_rate`  
   - `exam_results` 문서에 저장.
3. **통계 갱신**  
   - `users/{uid}/stats/{certCode}`에 과목/유형/개념별 correct·total·proficiency 갱신 (별도 문서).
4. **마이페이지 진입**  
   - `fetchDashboardStats()`: `exam_results` 최근 5건 + `stats` 1건 읽어서  
     - 예측 합격률: 최근 3회 가중 평균 또는 최신 1회  
     - 과목별 안전도: `latestSubjectScores` 우선 → 점수·안전 마진·트렌드 계산.

## 5. 규칙 요약 (기능 유지)

- **예측 합격률**  
  - 매 제출 시 1회만 계산, 시그모이드 + 난이도 보정, 96% 상한.  
  - 과락선 미만 과목이 있으면 원점수 단계에서 패널티로 반영.
- **과목별 안전도**  
  - “최근 시험의 과목별 점수” 우선, 없으면 누적 통계.  
  - 안전 마진 = (과목 점수 − 40).  
  - 합격률과 동일한 0~99 스케일로 통일.
- **표시**  
  - 학습 이력이 있을 때만 대시보드에 과목별 안전도·취약 개념·유형별 분석 노출.

### 5.1 15% 하한은 “표시 전용” (실제 합격·과락과 무관)

- **실제 합격·과락 판정**에는 **15% 하한을 적용하지 않습니다.**
  - 합격 여부(`is_passed`): `subject_scores` **실제 값**으로만 판단. 한 과목이라도 `min_subject_score`(예: 40) 미만이면 과락·불합격.
  - 예측 합격률·과목별 안전도의 **15% 하한**은 “보여주는 숫자”만 조정하는 용도(절망적인 0% 방지)이며, 저장되는 `exam_results.subject_scores`나 합격/과락 로직은 그대로 0점도 허용.
- **과락선은 40점 그대로**입니다. 15%를 “올린다”는 의미가 아닙니다.
  - “과락 안정” = 해당 과목 점수가 **40점 이상**이면 과락 아님. 75% 이상이어야 한다는 규칙은 없으며, 40점이 공식 과락선입니다.
  - 대시보드에서 15%로 보여줘도, 안전 마진 = 15 − 40 = −25로 **과락 위험**으로 표시됩니다.

### 5.2 15%는 “밑에 깔린 기본값”이 아님 (해석 시 주의)

- **15%는 하한(floor)만 적용**됩니다. `표시값 = max(15, 계산된 점수)` 이므로, **계산된 점수에 15를 더하는 것이 아닙니다.**
- 따라서 **60%로 보이면 = 실제(또는 blended) 안전도가 60%**라는 뜻입니다. “60 − 15 = 45%가 진짜”가 **아니라**, 60%로 해석하면 됩니다.
- 15%가 적용되는 경우는 **계산된 점수가 15 미만일 때만** (예: 0, 10) 그때만 15로 올려서 표시합니다. 학습자가 “15%를 기본으로 깔고 가서 숫자가 부풀려진다”고 오해할 필요 없도록, UI/도움말에서 “과목별 안전도는 0~100%이며, 매우 낮을 때만 최소 15%로 표시됩니다” 정도로 안내해 두는 것이 좋습니다.

## 6. 사업계획서용 요약 문구 (한국어)

아래 문단은 그대로 또는 약간만 수정해 사업계획서·제안서에 넣을 수 있도록 작성한 요약입니다.

### 6.1 한 줄 요약

- “모의고사 채점 결과를 바탕으로 **예측 합격률**(시그모이드 적용)과 **과목별 안전도**(과락선 대비 마진)를 계산해, 학습자가 자신의 합격 가능성과 과목별 위험을 한눈에 보도록 합니다.”

### 6.2 예측 합격률 (2~3문장)

- “**예측 합격률**은 ‘지금 실력이면 실제 시험에서 합격할 확률’을 0~99%로 보여주는 지표입니다. 과목별 점수의 평균을 내고, 한 과목이라도 과락선(40점) 미만이면 패널티를 주어 원점수 합격률을 구한 뒤, **시그모이드 변환**을 적용해 합격선(60점) 근처에서 작은 실력 차이도 %로 잘 드러나게 했습니다. 해당 회차 시험 난이도를 반영한 보정을 거쳐 최종 수치를 산출하며, 마이페이지와 시험 목록에서 최근 결과 또는 최근 3회 가중 평균으로 표시합니다.”

### 6.3 과목별 안전도 (2~3문장)

- “**과목별 안전도**는 각 과목의 정답률(0~99%)을 막대 등으로 보여주고, **안전 마진**(과목 점수 − 과락선 40점)으로 ‘과락 위험 여부’를 직관적으로 알 수 있게 합니다. 표시할 점수는 **가장 최근에 본 모의고사의 과목별 점수**를 우선 사용해, 예측 합격률과 같은 기준(같은 스케일)으로 해석할 수 있도록 했습니다. 과목별로 최근 추이(상승/하락/유지)도 함께 제공해, 어떤 과목을 보강해야 할지 결정하기 쉽게 했습니다.”

### 6.4 유저 플로우 (1~2문장)

- “사용자가 모의고사를 제출하면 서버에서 과목별 점수·합격 여부·예측 합격률을 한 번에 계산해 저장하고, 마이페이지에 들어가면 **최근 시험 결과**와 **누적 통계**를 합쳐 예측 합격률·과목별 안전도·취약 개념·유형별 분석을 한 화면에서 볼 수 있습니다.”
