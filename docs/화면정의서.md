# 화면정의서 (Screen Specification)

> **목적**: AI 에이전트가 UI/와이어프레임·디자인을 생성할 때 참조. 각 화면의 정의·목적·필수 기능·주요 UI 요소를 구체적으로 기술.  
> **범위**: 실서버(프로덕션) 기준. 베타 전용 화면/플로우는 "(실서버 추후 구현 예정)"으로 표기.

## 2. 화면별 상세 정의

### 2.1 랜딩(홈) — `/`

- **정의**: 서비스 최상위 진입 화면. 비로그인/로그인·관리자 여부에 따라 표시 내용이 달라짐.
- **목적**: 비로그인 사용자에게 무료 체험(진단) 유도, 로그인 사용자에게 대시보드 또는 관리자 화면 제공.
- **필수 기능**
  - 비로그인: 브랜드명·서비스 소개·「무료 진단 시작」 또는 자격증 카드 클릭 → `/exam-list` 또는 진단 플로우 진입. (실서버: 무료 20문항 후 로그인 유도.)
  - 로그인 + 일반: 대시보드(마이페이지)와 동일한 콘텐츠 또는 `/mypage`로 리다이렉트.
  - 로그인 + isAdmin: 관리자 대시보드(회원·문제·결제 등 메뉴) 표시.
- **주요 UI 요소**
  - 상단: 로고·브랜드명. (사이드바 사용 시 LNB에 홈·마이페이지·로그인/로그아웃.)
  - 본문: 자격증별 카드 또는 CTA 버튼(무료 진단·학습 시작 등).
  - 로그인 유도 문구·버튼(비로그인 시).
- **이동 경로**
  - → `/exam-list`: 진단/모의고사 시작.
  - → `/mypage`: 로그인 후 대시보드.
  - → `/admin`: 관리자 로그인 시.
  - 모달: 로그인·회원가입(경로 없이 전역 모달).

---

### 2.2 마이페이지(대시보드) — `/mypage`

- **정의**: 로그인 사용자의 학습 현황·진도·다음 액션을 한 화면에 모아 보여주는 대시보드.
- **목적**: 예측 합격률·과목별 실력·회차별 점수 추이·취약 영역·집중학습 진입을 제공해 "다음에 무엇을 할지" 결정하게 함.
- **필수 기능**
  - **예측 합격률**: 최근 진단(1~3회차) 기반 가중 평균 합격률 표시. (3회차 미만이면 진행률 표시.)
  - **과목별 정답률(또는 안전도)**: 과목별 막대/게이지·안정권/보완/집중 필요 라벨.
  - **회차별 점수 추이**: 차트(라인 등)로 1회차~N회차 점수·합격 여부.
  - **취약 개념/유형**: 상위 N개 취약 영역 표시.
  - **집중학습 CTA**: 과목 강화·취약 유형·취약 개념 각 50문항(또는 N문항) 학습 시작 버튼.
  - **다음 회차/모의고사 시작**: 선택한 자격증 기준 다음 회차 카드 또는 「모의고사 목록」 → `/exam-list`.
  - 오답 노트/재풀이: 회차별 오답 목록 보기·재풀이 이동.
- **주요 UI 요소**
  - 카드/섹션: 예측 합격률, 과목별 점수, 회차 추이 차트, 취약 Top3, 집중학습 버튼 그룹, 최근 응시 목록.
  - 네비게이션: LNB에서 마이페이지·설정·모의고사 목록·로그아웃.
- **이동 경로**
  - → `/exam-list`: 모의고사/회차 선택.
  - → `/quiz`: 집중학습 또는 회차 재풀이 시.
  - → `/account-settings`: 계정 설정.
  - → `/`: 로그아웃 시 또는 홈.

---

### 2.3 계정 설정 — `/account-settings`

- **정의**: 로그인 사용자의 프로필·이용권·보안 관련 설정 화면.
- **목적**: 이용권 확인·비밀번호 재설정·로그아웃 등 계정 관리를 한 곳에서 수행.
- **필수 기능**
  - 이용권(멤버십) 표시: 자격증별 유료 기간·만료일.
  - 비밀번호 재설정: 이메일 발송 또는 인앱 변경(구현 여부에 따름).
  - 로그아웃 버튼.
  - (선택) 프로필 수정·탈퇴. (탈퇴는 실서버 추후 구현 예정 문서 참고.)
- **주요 UI 요소**
  - 목록/카드: 자격증별 이용권 상태.
  - 버튼: 비밀번호 재설정, 로그아웃, 뒤로가기(→ `/mypage`).
- **이동 경로**
  - ← `/mypage`: 뒤로가기.

---

### 2.4 모의고사 목록 — `/exam-list`

- **정의**: 선택된 자격증(또는 기본 자격증)의 회차 목록. 각 회차를 카드/목록으로 보여주고, 클릭 시 모드 선택 후 퀴즈로 진입.
- **목적**: 1~3회차(고정)·4회차~(맞춤형/약점 공략)를 구분해 표시하고, 권한에 따라 잠금/이용 가능 상태를 명확히 전달.
- **필수 기능**
  - **회차 카드 목록**: 1회차, 2회차, 3회차, 4회차~(약점 공략 1회, 2회 …) 등. 회차명·부가 설명·문항 수 표시.
  - **상태 표시**: 완료(체크)·진행 가능·잠금(무료는 3회차부터 잠금, 유료는 전 회차 이용 가능).
  - **클릭 시**: 모드 선택 모달(학습 모드 / 실전 모드). 4회차 이상은 "맞춤형 문항 준비 중" 오버레이(예: 5초) 후 퀴즈 로드.
  - **뒤로가기**: `/mypage` 또는 `/`.
- **주요 UI 요소**
  - 회차 카드: 제목·설명·문항 수·잠금 아이콘/배지·완료 표시.
  - 모달: 학습 모드 / 실전 모드 선택 버튼.
  - 오버레이: "모의고사 큐레이션 중…" 또는 "맞춤형 모의고사가 준비되었습니다" 문구.
- **이동 경로**
  - ← `/mypage` 또는 `/`: 뒤로가기.
  - → `/quiz`: 회차·모드 선택 후 퀴즈 시작.

---

### 2.5 퀴즈 화면 — `/quiz`

- **정의**: 한 회차의 문항을 순서대로 풀고 제출하는 화면. 학습 모드(문항별 즉시 채점·해설)와 실전 모드(일괄 채점) 지원.
- **목적**: 제한 시간·선택지·플래그(모르겠음·헷갈림)·제출을 통해 응시 데이터를 수집하고, 채점·stats·Elo 반영의 입력이 됨.
- **필수 기능**
  - **문항 표시**: 지문·이미지·선택지(1~5 등). 문항 번호·진행률(예: 12/80).
  - **선택**: 단일 정답 선택. 선택 후 「제출」 또는 「다음」.
  - **플래그**: 「모르겠어요」 선택 시 정답 0으로 처리. (선택) 「헷갈려요」 체크(학습 모드). 실전 모드에서는 채점 시 풀이 시간으로 헷갈림 자동 판정.
  - **학습 모드**: 문항 제출 시 즉시 정답/오답·해설·wrong_feedback 표시 후 다음 문항.
  - **실전 모드**: 모든 문항 풀이 후 일괄 제출 → 결과 화면으로 이동.
  - **타이머/경과 시간**: 문항별 elapsedSec 기록(헷갈림·찍기 판정에 사용).
  - **이탈/일시정지**: (선택) 브라우저 이탈 시 복귀 시 이어하기 또는 경고.
  - **문제 신고**: (선택) 문항별 「오류 신고」 버튼 → problem_reports 저장.
- **주요 UI 요소**
  - 상단: 진행률 바·문항 번호·(선택) 남은 시간.
  - 본문: 지문·이미지·선택지 라디오/버튼.
  - 하단: 모르겠어요·헷갈려요(학습 모드)·이전/다음·제출.
  - 오류 신고 플로팅 버튼 또는 문항 하단 링크.
- **이동 경로**
  - → `/result`: 제출 완료 후 결과 화면.
  - ← 이전 문항(같은 화면 내). 게스트 20문항 후 로그인 유도 시 모달 → 로그인 후 이어하기 또는 결제.

### 2.6 결과 화면 — `/result`

- **정의**: 퀴즈 제출 후 한 회차의 채점 결과를 보여주는 화면. 과목별 점수·합격 여부·예측 합격률·오답 목록·CTA.
- **목적**: 합격/불합격·과목별 강약·예측 합격률을 전달하고, 다음 액션(다시 풀기·다음 회차·대시보드·결제)으로 유도.
- **필수 기능**
  - **총점/과목별 점수**: 과목별 점수(막대/테이블). 과락선(40점 등) 미만 강조.
  - **합격/불합격**: 기준 충족 시 합격·불합격 뱃지/문구.
  - **예측 합격률**: 해당 회차 기준 예측 합격률(%). (3회차 이후부터 제공 등 정책에 따름.)
  - **오답/피드백**: 오답 문항 목록·해설·헷갈림/찍기 배지(표시 시).
  - **CTA**: 다시 풀기, 다음 회차, 대시보드로 가기, 결제하기(무료 회원 3회차 후 등).
- **주요 UI 요소**
  - 요약 카드: 총점·합격 여부·예측 합격률.
  - 테이블/카드: 과목별 점수.
  - 리스트: 오답 문항 접기/펼치기·해설.
  - 버튼: 다시 풀기, 다음 회차, 대시보드, 결제.
- **이동 경로**
  - → `/quiz`: 다시 풀기(동일 회차).
  - → `/exam-list`: 다음 회차 선택.
  - → `/mypage`: 대시보드.
  - → `/checkout`: 결제 유도.

### 2.7 결제(체크아웃) — `/checkout`

- **정의**: 회차별 이용권(또는 정기권) 구매·쿠폰 적용 화면. (실제 PG 연동 여부는 Phase에 따름.)
- **목적**: 유료 전환·할인/쿠폰 적용·결제 완료 후 이용권 활성화까지 안내.
- **필수 기능**
  - 자격증·회차(또는 상품) 선택.
  - 가격·할인·쿠폰 입력(선택).
  - 결제하기 버튼 → (구현 시) PG 연동 또는 "준비 중" 안내.
  - 결제 완료 시 memberships/이용권 갱신 후 `/exam-list` 또는 `/mypage` 이동.
- **주요 UI 요소**
  - 폼: 상품 선택·수량·쿠폰 코드·결제 수단.
  - 요약: 금액·할인·최종 결제액.
  - 버튼: 결제하기, 취소(뒤로가기).
- **이동 경로**
  - ← `/exam-list` 또는 `/mypage`: 취소/뒤로가기.
  - → `/exam-list` 또는 `/mypage`: 결제 완료 후.

---

### 2.8 관리자 대시 — `/admin`

- **정의**: isAdmin 사용자 전용 대시보드. 메뉴: 대시(통계)·회원관리·문제관리·결제/쿠폰·(선택) 베타.
- **목적**: 회원·문제·결제·쿠폰·오류 로그 등 운영 관리를 한 진입점에서 수행.
- **필수 기능**
  - **대시**: 오늘 방문자·회원 수·(선택) 오류 로그 요약.
  - **회원관리**: 회원 목록(페이징)·검색·필터. 행별: 수기 결제/권한 수정, 학습현황 확인하기, 메모, 비밀번호 재설정, 기기 초기화, 이용 정지/해제. 학습현황 모달: 회차별 점수·합격률·현재 Elo.
  - **문제관리**: `/admin/questions`로 이동. 자격증·회차·과목 필터·문항 수정·이미지.
  - **결제/쿠폰**: `/admin/billing` 또는 내부 탭. 쿠폰 등록·목록·폐기.
  - **자격증 관리**: `/admin/certs`. 시험일정 등 설정.
- **주요 UI 요소**
  - LNB: 대시, 회원 관리, 문제 관리, 결제/쿠폰, 자격증, (선택) 베타.
  - 테이블: 회원 목록(이메일·이름·가입일·상태·자격증·학습현황 버튼·관리 드롭다운).
  - 모달: 결제 수정, 메모, 학습현황(회차별 점수·합격률·Elo), 정지/해제, 기기 초기화 확인.
- **이동 경로**
  - → `/admin/certs`, `/admin/questions`, `/admin/billing`: 메뉴 클릭.
  - ← 앱 메인: 로그아웃 또는 브랜드 클릭 시 `/` 등.

### 2.9 로그인/회원가입 모달

- **정의**: 전역 모달. 로그인·회원가입·(베타) 쿠폰 입력을 한 모달에서 처리. (실서버: 추후 쿠폰 단계 구현 예정.)
- **목적**: 인증·쿠폰 등록(베타) 후 서비스 이용 권한 부여.
- **필수 기능**
  - 탭 또는 전환: 로그인 / 회원가입.
  - 로그인: 이메일·비밀번호. (베타: 구글만 노출 가능.)
  - 회원가입: 이메일·비밀번호·이름 등. (이메일 인증 정책에 따름.)
  - 구글 로그인 버튼.
  - (베타, 실서버 추후) 쿠폰 입력 단계: 로그인 성공 후 쿠폰 없으면 쿠폰 코드 입력 → redeem 후 대시/목록 이동.
  - 비밀번호 재설정 링크(이메일 발송).
- **주요 UI 요소**
  - 입력 필드: 이메일, 비밀번호, 이름(회원가입).
  - 버튼: 로그인, 회원가입, 구글 로그인, 쿠폰 확인(베타).
  - 닫기: (비베타) X 버튼. (베타 강제 로그인 시 persistent.)
- **이동 경로**
  - 닫힐 때: 의도에 따라 `/mypage`, `/exam-list`, 퀴즈 이어하기 등.

### 2.10 오리엔테이션(OT) 팝업 — (실서버 추후 구현 예정)

- **정의**: 최초 진입 또는 미완료 사용자에게 서비스 소개·레벨 선택·쿠폰 입력을 유도하는 다단계 팝업.
- **목적**: 난이도(레벨) 선택·쿠폰 등록·핵심 기능 안내로 이탈 감소·전환 극대화.
- **필수 기능**
  - 단계: 업데이트 안내(선택)·레벨 선택(초급/중급/고급 등)·슬라이드(학습 vs 실전, 맞춤형, 대시보드)·쿠폰 입력(선택)·완료.
  - 레벨 선택 시 prepLevel 저장 → 진단 1회차 Elo 초기값 반영.
  - 쿠폰 입력 시 redeem → memberships 갱신 후 팝업 닫기.
  - (베타) forced 시 닫기 버튼 없음. 완료 후에만 닫기.
- **주요 UI 요소**
  - 슬라이드: 제목·본문·이미지(선택). 이전/다음.
  - 라디오/버튼: 레벨 선택.
  - 입력: 쿠폰 코드.
  - 버튼: 다음, 이전, 완료, 새 진단 시작하기(업데이트 안내 후).
- **이동 경로**
  - 완료 후: `/exam-list` 또는 `/mypage`. (신규 가입 후 1회만 「가입 완료」 토스트/팝업 후 이동.)

## 3. 공통 UI 요소

- **상단/사이드바(LNB)**: 로고·홈·마이페이지·(로그인 시) 계정/설정·로그아웃. 관리자일 때 Admin 메뉴.
- **토스트/알림**: 성공·오류 메시지 단기 표시(하단 또는 상단 고정).
- **로딩**: 전역 스피너 또는 스켈레톤. 퀴즈 문항 로드·큐레이션 중 오버레이.
- **에러**: 권한 없음(403)·네트워크 오류 등 공통 에러 메시지·재시도 버튼.

## 4. 반응형·접근성
